# 综合结论必须与检测覆盖度同时呈现

ipcheck Web 只能完成约半数检测项，且无法完成的那半恰好包含 ipcheck CLI 中判定**最高风险**的输入（Claude 中转端点命中黑名单）。我们决定综合结论照常给出低/中/高三档，但强制与覆盖度一起呈现（如「本次覆盖 5 项，另有 5 项需 CLI 检测」）；任何只显示档位、不显示覆盖度的呈现都视为缺陷。

## Consequences

- 目标用户是"启动 Claude 前想确认自己不会被封号"的人。一个不标覆盖度的绿色「低风险」，会在最可能导致封号的那一项根本没测的情况下给出安全感——这是主动误导，比不给结论更有害。
- 同类站 whoer.net 的「Your disguise: 90%」正是不标覆盖度的做法。它是被明确**拒绝**的参照，不是模仿对象。
- 该约束适用于一切呈现形态：首屏结论、可复制的分享文案、未来可能开放的 API 响应。
