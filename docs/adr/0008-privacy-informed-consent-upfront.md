# 隐私立场：第三方调用前置知情同意，自身零留存

用户点击「检测 IP 风险」时其出口 IP 必然被发送至 proxycheck.io；IPv6 检测中浏览器直连 ipify，ipify 同样可见其地址。"我们不存储"与"没有第三方看见"是两回事。我们决定把第三方调用写在触发按钮上（点击即知情同意），页脚声明本站不存储任何检测结果，并关闭 Workers 侧的请求日志。

## Considered Options

- **页脚一句"我们不记录"，不提第三方** — 否决：本产品的用户群是最会读这行小字、也最可能真的去抓包核实的人；一旦被发现隐去了第三方调用，信任即归零，而信任是这个产品唯一的资产。
- **完整隐私政策页** — 否决：无流量阶段的纯负担，且长篇政策的实际可信度低于按钮旁一句大白话。

## Consequences

- 任何新增的第三方调用，必须在触发它的那个控件上同步标注，否则视为违反本 ADR。
- 与 [ADR-0002](./0002-no-kv-for-rate-limiting.md)（不引入 KV/D1）一致：不落库不是性能取舍，是隐私承诺的技术兑现。
- 需实测确认 Cloudflare Workers Observability 默认是否记录客户端 IP 及其关闭方式——该项列为上线前阻塞验收项。
