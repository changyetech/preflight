# 新增分流泄露两项（O5 DNS 出口泄露 / O6 UDP 出口一致性），分母 8 → 10

ipcheck 原有的 8 项检测里，除 IPv6 泄露外，全部结论都建立在**一条 TCP/HTTPS 连接**的观测上——出口 IP、归属、时区、风险分，都是「我发一个 HTTP 请求，对端看到谁」。但用户真正想知道的问题是**代理有没有接管全部流量**，而 TCP/HTTP 走代理、DNS 与 UDP 却走直连，恰恰是系统代理／PAC 模式下最常见的两条漏。这两条漏对着一条 TCP 连接测一万次也测不出来。

我们新增 **O5（DNS 出口泄露）** 与 **O6（UDP 出口一致性）**，覆盖度分母从 8 涨到 10。

同时偿还一笔既有的债：契约把 C2 写作「本地 DNS 服务器**与 DNS 泄露**」，而实现（`cli/src/probe/dns.rs`）自始至终只读本机 DNS **配置**，从未做过一次泄露探测。C2 的措辞因此**收缩**为「本地 DNS 服务器配置」，泄露判定归 O5。

**为什么值得记一份 ADR**：分母刚从 9 砍到 8（[ADR-0013](./0013-drop-vendor-endpoint-check.md)），转头又涨到 10——没有上下文的人会认为我们在反复横跳；ID 不复用与分母变更都是难以逆转的决定；而下面每一条被否决的方案都不是稻草人，其中两条是盘问中途一度被采纳、又被实测推翻的。

## 判据的选择

- **O5 比的是 ECS（EDNS Client Subnet）客户端子网的归属国 vs 出口 IP 归属国。** ECS 是 resolver 转发查询时附带的「客户端在哪」，反映的是**客户端**，不是 resolver 自己。
- **O6 需要 ≥2 个互相独立的 STUN 报出同一个反射地址、且该地址 ≠ 出口 IP 才判命中；两个 STUN 各报各的则是「无从比对」，不贡献信号。** 这是 [ADR-0003](./0003-ipv6-leak-via-third-party-dual-stack-echo.md)「用对照区分未知与未命中」原则的第二次应用。

判定的完整规则在契约 [docs/verdict.md](../verdict.md) §2.5／§2.6，本文只记为什么是它、以及否决了什么。

## Considered Options

- **把两项合并成一项「分流泄露」。** 否决：DNS 与 UDP 是两次独立的探测，「DNS 测成了、UDP 没测成」是常态（浏览器禁用 WebRTC 时必然发生）。合成一项后这个状态在覆盖度上**无法诚实表达**——只能在「已完成」和「检测失败」里挑一个说，两个都是谎。而覆盖度是本产品唯一的诚实性机制（[ADR-0004](./0004-verdict-must-state-coverage.md)），为了少一行卡片牺牲它，方向是反的。

- **用 resolver 自身的归属国（`dns.geo`）作判据。** 否决：**这是一次会打中我们典型用户的系统性误报。** resolver 在哪个国家取决于用户**选了哪家 DNS 服务商**，与流量走没走代理毫无关系：把 DNS 设成 `223.5.5.5` 且开着全局 TUN 的用户，查询经隧道到达阿里、阿里再从中国出去查权威——resolver 归属国 = 中国 ≠ 出口国，判「泄露」，而这个用户的配置**完全正确**。这个组合在本产品的用户群里极常见。这一版判据在盘问中途一度被采纳，是第 0 步实测把它推翻的。resolver 归属国仍然展示（它对排查有用），但不进判定。

- **比 ECS 的 IP 前缀是否落在出口 IP 的同一网段。** 否决：**掩码敏感。** ECS 的掩码位数由 resolver 决定，且响应里不一定给出——Google 与阿里用 /24，但这不是标准要求，别家用 /20、/16 都合法。按 /24 比，遇到 /20 的 resolver 就是误报；按最宽的比，就什么都测不出来。比国家没有这个问题：掩码多宽都不改变它落在哪个国家。

- **跟参考站一样，把「浏览器禁用 WebRTC」渲染成绿色的「未泄露」。** 否决：**在我们的语义下绿色是错的。** 参考站测的是「WebRTC 会不会泄露你的 IP」，禁用 WebRTC 确实消除了那个泄露面，绿色成立。我们测的是「UDP 流量走没走代理」——禁用 WebRTC 只是把测量仪器关掉了，UDP 该怎么走还怎么走。把关掉仪器说成没问题，正是本项目最要防的那类误报（[ADR-0004](./0004-verdict-must-state-coverage.md)）。因此落「检测失败」，由覆盖度诚实呈现。这是与参考站的**刻意分歧**，不是没注意到。

- **把 O6 降级成分项提醒（只亮黄、不进综合结论），以躲开多出口集群与对称 NAT 的误报。** 否决：误报有更诚实的解法。多出口集群与对称 NAT 的共同特征是**两个 STUN 会报出不同的反射地址**——用对照法它们会自己暴露，落进「无从比对」，根本不需要用降级去绕。用降级换安全，代价是一个**确定**的 UDP 绕行（两个 STUN 一致地指向另一个 IP）也永远影响不了结论，那才是真正的漏报。

- **两个新信号给「高」档。** 否决：契约 §3.2 的不变量「『高』只可能出现在 `full` 形态」，靠的是**唯一的高档信号 `riskScoreHigh` 来自 O4**。任何不依赖 O4 的高档信号会当场打破它——一个确定的分流泄露会在 proxycheck 失败或配额耗尽时被压成「初步 · 中」，即形态与档位互相污染。两项因此**均为「中」档**，与 `ipv6Leak` 同级（它们暴露的都是位置信息，不像风险分那样直接关联封号）。

## Consequences

- **覆盖度分母恒为 10**：Web `X + Y + Z + W = 10`，CLI `X + Z = 10`。「需 CLI」仍为 **4**（C1–C4）——O5／O6 是两端都能测的可在线项。
- **新 ID 为 `O5` / `O6`。`C5` 仍是废弃编号，不复用**（[ADR-0013](./0013-drop-vendor-endpoint-check.md) 的规则原样成立）。
- **C2 的能力承诺被收缩**（「与 DNS 泄露」→「配置」）。这是**还债，不是砍功能**：被删掉的是一句从未兑现的措辞，没有任何实现行为随之消失。契约 §1 留了一条跨版本比对的提示——同一个 `C2` 在旧版本的文字里承诺过更多。
- **新增一份两端共享的数据文件 [docs/country-codes.json](../country-codes.json)**（英文国家名 → ISO2）。它与 ADR-0013 砍掉的「会腐烂的清单」**不是同类**：ISO 3166-1 是十年尺度稳定的标准，而且它一旦出错，错的是一次「查不到」（按契约 §2.3 退化为未知、不贡献信号），不会把误判包装成安全结论。约定也钉死了这一点：**查不到一律未知，不得回退成「不同国家」**。
- **代价：O5 的 provider 是单点，且这个口子未定价。** `https://ip-api.com/json/` 对免费版返回 403，而 `https://<随机前缀>.edns.ip-api.com/` 可用——这个不对称随时可能被收紧。届时 O5 在 Web 侧直接失效（CLI 还能退回 HTTP，浏览器不能，混合内容会被拦）。实测已排除另外三家：`ipleak.net` 与 `browserleaks.net` 的通配符子域解析不出来，`surfsharkdns.com` 不给 ECS（只够支撑被否决的 resolver 归属判据）。我们接受单点，前提是**它的失败态是响亮且可重试的**（落「检测失败」，不是静默判绿）。
- **代价：不发 ECS 的用户永久拿不到 O5 结论。** Cloudflare `1.1.1.1` 明确不发 ECS，而它正是本产品典型用户的常见选择。这是真实的覆盖损失，由覆盖度诚实呈现——该情形记「已完成 · 无从比对」并说明原因，**不记检测失败**（刷新一万次也一样，不该诱导用户去刷）。
- **代价：O6 要联系两个 STUN，「少暴露一方」只守住一半。** `stun.cloudflare.com` 不新增观察者（本站本就跑在 Cloudflare 上），但对照必须要第二家，那一家是净新增的第三方。对照法是 O6 判据成立的前提，这笔账我们认。
- **两端会在这两项上出现新的、消灭不掉的分歧**，已登记为契约 §5.5（浏览器 DoH vs 系统 resolver）与 §5.6（WebRTC 栈 vs 裸 UDP socket），受 [ADR-0011](./0011-capability-boundary-divergence.md) 管辖。与 §5.1 一样，**Web 侧是降级代理**：用户关心的是命令行工具走的那条路径，那是 CLI 才测得到的。
- **CLI 侧用手写的 RFC 5389 STUN binding request（裸 `UdpSocket`）**，以保住 [ADR-0010](./0010-verdict-contract-normative-cli-full-implementation.md) 的「CLI 是全集实现」，且不引入新 crate、不引入 tokio。
- **不引入脱敏／info-mask 机制**：O1 与 C1 已明文展示 IP，单给 O6 的反射地址加模糊是两套标准。真要做是一个独立需求，不搭这次的车。
