# ipcheck Web — 落地内容与国际化

- 父计划：[2026-08-10-ipcheck-web.md](./2026-08-10-ipcheck-web.md)
- 实现规格：[docs/specs/2026-08-10-ipcheck-web.md](../specs/2026-08-10-ipcheck-web.md) 第 4 / 6 / 7 节
- Depends on: `--ui-panel`

## 目标

补齐检测面板之下的落地内容与中英双语，兑现 ADR-0001 的「CLI 门面」定位与 ADR-0008 的隐私声明。

## 范围

**包含**：「为什么需要」「安装 CLI」「Web 与 CLI 完整功能对照表」三段内容、页脚隐私声明、`/en` 英文版、语言切换。

**不包含**：FAQ 页、文档站、报告分享（规格明确排除在 v1 之外）。

## 步骤

1. 撰写「为什么需要」段落，内容对齐 CLI README 的四类风险（IPv6 泄露 / DNS 泄露 / IP 风险 / 时区不一致），但**不得声称本站能检测 DNS 泄露**
   → verify：通读确认无越权承诺
2. 撰写「安装 CLI」段落，含 `pip install ai-ipcheck` 与一键复制
   → verify：复制按钮实测可用
3. 撰写「Web 与 CLI 完整功能对照表」，9 项逐行标注哪边能测
   → verify：表格行数为 9，与规格第 2 节总表逐项一致——两处不一致即为缺陷
4. 页脚隐私声明「本站不存储任何检测结果」
   → verify：文案存在性断言
5. 抽取全部面向用户的文案为可翻译资源，中文为默认
   → verify：无硬编码中文残留在组件内
6. 实现 `/en` 路径与右上角手动切换；**不实现 `Accept-Language` 自动跳转**
   → verify：以 `Accept-Language: en` 请求根路径，仍返回中文版
7. 英文文案翻译，术语与 CLI 的 `README_EN.md` 对齐
   → verify：关键术语（出口 IP / 综合结论 / 覆盖度）两版一一对应

## 验收标准

- 功能对照表 9 行与规格第 2 节总表完全一致
- 页脚隐私声明存在
- `Accept-Language` 不触发自动跳转
- 中英两版内容对等，无硬编码文案
