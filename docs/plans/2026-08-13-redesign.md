# 双端重设计 + 语种收缩（父计划）

- 实现规格：[docs/specs/2026-08-13-redesign.md](../specs/2026-08-13-redesign.md)
- 关联：[ADR-0016](../adr/0016-two-locales-en-zh-hans.md)

## 目标

按 `refs/ipcheck-web-redesign.html` 与 `refs/cli-report-redesign.html` 重做两端呈现层，语种收缩为 en/zh-hans。判级契约、`--json`、worker API 均不动。

## 子计划与执行顺序

1. [`--locales`](./2026-08-13-redesign--locales.md) — 语种收缩（两端 + 测试重写）。**先行**：Web/CLI 子计划都依赖收缩后的文案架构。
2. [`--web`](./2026-08-13-redesign--web.md) — Web 视觉/排版/主题重做。Depends on: locales。
3. [`--cli`](./2026-08-13-redesign--cli.md) — CLI 人读报告重排。Depends on: locales。与 `--web` 无依赖，可并行。

## 总验收

spec §8 的五条全部满足；每个子计划合并前各自 `make check`（web 侧）/ `make check-cli`（cli 侧）绿，最终 `make check-all` 绿。
