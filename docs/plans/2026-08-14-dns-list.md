# 公共 DNS 清单（父计划）

- 实现规格：[docs/specs/2026-08-14-dns-list.md](../specs/2026-08-14-dns-list.md)
- 关联：[docs/verdict.md](../verdict.md)、[docs/api.md](../api.md)——**均不动**

## 目标

新增两端共吃的公共 DNS 清单：CLI `preflight dns`（可选 `--check` 实测），Web 独立页面 `/dns/`。清单随版本内置，无远端拉取、无缓存、无新增 API 端点。

## 子计划与执行顺序

1. [`--data`](./2026-08-14-dns-list--data.md) — 契约数据 `docs/dns-servers.json` + CLI 侧注册表替换 `KNOWN_DNS`。**先行**：CLI 与 Web 子计划都依赖这份数据与其类型。
2. [`--cli`](./2026-08-14-dns-list--cli.md) — `preflight dns` 命令、`--check` 实测、`--json`。Depends on: data。
3. [`--web`](./2026-08-14-dns-list--web.md) — `/dns/` 与 `/zh-hans/dns/` 页面、`LOCALES.path` 改造、路由与 SEO。Depends on: data。与 `--cli` 无依赖，可并行。

## 总验收

spec §8 的七条全部满足；`--cli` 合并前 `make check-cli` 绿，`--web` 合并前 `make check` 绿，最终 `make check-all` 绿。
