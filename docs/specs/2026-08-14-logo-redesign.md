# Logo 重设计：Ascent 起飞（方向 A / 变体 A2）

- 日期：2026-08-14
- 状态：已批准（两轮方案对比 + 一轮变体调整后选定）
- 探索过程参考：`refs/preflight-logo-concepts.html`（三方向原稿）

## 背景

`public/favicon.svg` 仍是旧品牌遗留的紫色闪电图（旧 accent `#aa3bff` 时代产物）：
与现行仪表蓝 token 脱节、闪电隐喻与产品无关、内部 16 个模糊滤镜在小尺寸下不可辨。
顶栏以 `<img src="/favicon.svg">` 复用同一文件，站点无 og:image。

## 选定方案

**Ascent 起飞**：对勾的长笔画同时是起飞轨迹，从一条地平弧上升，
轨迹末段变绿 =「通过，可以起飞」。三层含义（体检勾 / 起飞轨迹 / 通过绿）一笔画完。

### 颜色约束（硬性）

- 主色：站点 accent 仪表蓝 `oklch(50% 0.145 250)`；深色主题 `oklch(72% 0.13 248)`。
- 辅色：仅允许通过态绿 `--ok`（浅 `oklch(43% 0.11 155)` / 深 `oklch(80% 0.14 155)`）。
- 红 / 琥珀绝不入图——判级语义色不得被品牌抢读。

## 落地点

1. **`public/favicon.svg`**：替换为简化层，内嵌 `prefers-color-scheme: dark` 颜色规则
   （favicon 跟随系统主题，站点 data-theme 管不到它，属预期行为）。
2. **顶栏 `src/components/Nav.tsx`**：`<img>` 改为内联 SVG（简化层，20×20），
   颜色取 `var(--accent)` / `var(--ok)`，跟随站点主题切换。
3. **og:image**：新增 `public/og.png`（1200×630，浅色底 + 全量 mark + Preflight 字标 + 副题），
   十个入口 HTML 各补 `og:image` 与 `twitter:card` meta（绝对 URL，两语种共用一张）。

## 品牌资产存放

大尺寸/母版资产在 `docs/assets/`：`logo.svg`（全量层矢量母版，随系统主题切换配色）、
`logo-1024.png` / `logo-1024-dark.png`（1024×1024 透明底，浅/深主题配色）、
`logo-1024-white.png`（1024×1024 纯白底，浅色主题配色）。
